# Einkaufsliste 🛒

Eine einfache Einkaufslisten-App fürs iPhone, die im Browser läuft und sich wie eine normale App auf den Home-Bildschirm legen lässt.

**Zur App:** https://sertscho.github.io/ShoppingList/

## Funktionen

- Artikel hinzufügen, abhaken und löschen
- Automatische Emojis pro Artikel (🥛 Milch, 🍞 Brot …)
- Schnellvorschläge zum Antippen
- Fortschrittsbalken und Bereich „Im Wagen“ für Erledigtes
- Hell- und Dunkelmodus
- Funktioniert auch offline
- Die Liste wird nur auf dem eigenen Gerät gespeichert

## Auf dem iPhone installieren

1. Die App-Adresse in **Safari** öffnen
2. Auf **Teilen** (Quadrat mit Pfeil) tippen
3. **„Zum Home-Bildschirm“** → **„Hinzufügen“**

## Dateien

| Datei | Inhalt |
| --- | --- |
| `index.html` | Aufbau der Seite |
| `style.css` | Aussehen |
| `script.js` | Funktionen der Liste |
| `manifest.webmanifest` | App-Name und Icon für den Home-Bildschirm |
| `sw.js` | Offline-Speicher |
| `icons/` | App-Icons |
